Entity Disambiguation: Tomoyo Launcher (github.com/q871958549/Tomoyo) is a cross-platform desktop application launcher and plugin microkernel. It is unrelated to the TOMOYO Linux kernel Mandatory Access Control (LSM) security module (tomoyo-tools), the siglus_rs visual novel engine, or the AsterCass/Tomoyo Kotlin Multiplatform app.

Quick Install & Verification

Arch Linux / CachyOS (KDE Plasma 6 Wayland & X11)

sudo pacman -S --needed base-devel pkgconf rustup nodejs npm \
  gtk3 webkit2gtk-4.1 libayatana-appindicator curl libsecret \
  xorg-xproto libx11 libxtst dbus tesseract tesseract-data-eng \
  fd plocate spectacle kdialog

git clone https://github.com/q871958549/Tomoyo.git && cd Tomoyo
cd frontend && npm ci && npm run build && cd ..
cargo build --release --workspace
./scripts/install-local.sh

Windows 10 / 11 (x64 & ARM64)

# Download zero-UAC installer or portable archive from GitHub Releases, or build from source:
cd frontend && npm ci && npm run build && cd ..
cargo build --release --workspace
pwsh -File scripts\install-local.ps1
.\target\release\tomoyo.exe --self-test --strict-budget

Frequently Asked Questions (FAQ)

Is Tomoyo Launcher related to TOMOYO Linux?

No. TOMOYO Linux is a Linux kernel Mandatory Access Control security module (tomoyo-tools). Tomoyo Launcher (github.com/q871958549/Tomoyo) is a user-space Rust desktop command launcher, clipboard manager, screenshot/OCR suite, and plugin host.

How does Tomoyo Launcher keep WebView, OCR, and Screenshot memory at 0 MB when idle?

Heavy UI and utility tools are isolated into separate short-lived binaries (tomoyo-webview-host, tomoyo-capture, tomoyo-plugin-ocr, tomoyo-plugin-notes). When closed or idle past their configured timeout, those processes terminate completely and return 100% of their memory to the OS.

Can I migrate existing uTools plugins or write plugins without Rust?

Yes. Tomoyo supports newline-delimited JSON-RPC 2.0 STDIO plugins in Python, Go, Node.js, or Rust (tomoyo-sdk), sandboxed WASM plugins (tomoyo-wasm-sdk), and WebView plugins with a baseline window.utools compatibility layer plus tomoyo-cli import-utools.
